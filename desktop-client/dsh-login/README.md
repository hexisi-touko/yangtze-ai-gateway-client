# 登录与桌面端集成

本目录包含客户端登录流程及登录后的桌面端集成代码：

- New API 登录、注册申请、找回密码和两步验证；
- Windows 安全存储中的凭据记忆；
- 账号权限校验和 Harness Host 启动；
- 模型目录、用量页面、终端工具同步和客户端更新日志；
- 登录页面及相关静态资源。

## 配置边界

服务端地址从桌面端配置读取，客户端只通过 HTTP API 与服务端通信，不直接访问数据库。认证凭据留在主进程和本地安全存储中，不通过渲染器 IPC 暴露。

打包运行时需要在本目录提供 `desktop.config.json`。部署流程应从目标环境注入该私有配置；不要将真实服务器地址或部署配置提交到仓库。
